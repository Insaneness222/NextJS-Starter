PROJECT GOAL
Create a fully runnable Next.js + TypeScript web app that demonstrates a research PoC: a 2D battlefield deployment simulator for multiple unmanned platforms (Artillery, Tank, UGV). The system selects and disperses optimal positions based on terrain/obstacles/threat using a weighted scoring model. The Demo page is the core deliverable.

TECH STACK (MANDATORY)
- Next.js (App Router)
- TypeScript
- TailwindCSS
- State management: Zustand
- Rendering: HTML Canvas (preferred)
- Charts (optional): recharts
- Dark mode
- Fully client-side (no backend required)

3.4 Line-of-Sight (LoS) / Exposure Model
Implement grid raycasting using Bresenham in /lib/raycast.ts.
Rules:
- Building blocks LoS completely.
- Forest attenuates LoS (e.g., multiply by 0.6 per forest cell intersected; keep it simple and stable).
- Hill affects elevation advantage; LoS blocking by hill is optional (if too complex, skip hill blocking and use hill only for elevation/cover scoring).
Provide toggles (bilingual):
- LoS On/Off
- Threat Cone On/Off
- Distance Attenuation On/Off

3.5 Scoring Function (platform-specific weights)
Implement in /lib/scoring.ts:
score =
  w_vis * FriendlyToEnemyVisibility
- w_exp * EnemyToFriendlyExposure
+ w_cov * CoverScore
+ w_ele * ElevationAdvantage
+ w_mob * MobilityScore
- w_sep * SeparationPenalty

Provide platform templates (bilingual) that set default weights:
- Artillery Template (prioritize open space / distance / mobility; lower exposure concern)
- Tank Template (prioritize low exposure / cover / good LoS)
- UGV Template (balance mobility + cover + repositioning)
Also provide Custom mode with sliders (0–1) for each weight.

3.6 Multi-Unit Deployment Algorithm
Implement:
- Candidate generation: all walkable cells or sampled cells (add a sampling density slider).
- Two execution modes:
  - One-shot Solve: compute and place all units at once.
  - Step-by-step: place units sequentially and visualize placement per step.
Constraints:
- Minimum distance between units (avoid clustering/collision).
- Diversity penalty to avoid selecting identical top spots.
Show selected positions with distinct icons/colors per platform.
